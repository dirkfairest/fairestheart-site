Researchers

Days of background ECG with the moments the participant marked.

A single-lead ECG from a Polar H10 on the participant's own phone, written as EDF+. All day, all night, for as many days as the study runs. Codes per participant, a format page, a sample file.

Who it is for

Labs that already use the H10 and want days, not sessions.

The H10 is in hundreds of papers. Most of that work is a session in a lab with a phone tethered to a laptop. Fairest Heart records on the participant's phone, without a laptop, for as long as the strap is worn, and keeps the moments the participant tapped as annotations in the same file.

What a participant does

Wears the strap. Taps the bar when something happens.

Wears the strap

The app records all day and all night, by itself, as soon as the strap connects. Lab-owned phones or the participant's own.

Taps the bar

When something happens, one tap marks the moment. The participant can add what they felt or were doing, or a note, later.

The file is on the phone

Every recording is copied to Download/FairestHeart as EDF+ and CSV, and survives removing the app.

The lab gets it

The participant shares it from the app to the lab's address, or the lab copies the folder over USB from a lab phone. No server either way: nothing leaves the phone unless it is shared.

The file

Plain EDF+. Any reader that knows the format opens it.

The sample below is a synthetic heart with three marks, written by the same code the app uses. Open it in the viewer on this site, which reads the file in your browser and uploads nothing, or in EDFbrowser or any EDF+ reader.

ECG130 samples per second, in µV. One bipolar chest lead, raw from the strap: no filter is applied to what is stored.
AccelerometerACC X, ACC Y, ACC Z, 25 samples per second, in mG, placed on the ECG time axis.
Later filesAlso carry the R-R intervals and a signal-quality channel (one value per second, “SigQual”, in %).
RecordsOne second each.
One recordingEDF+C: continuous records.
A group of recordingsEDF+D, for a group with gaps between files. Each gap is annotated with its length and why.
MarksAn annotation Mark <label> at the moment the participant tapped, for example Mark fluttering / racing or Mark short of breath. A free note reads Mark followed by the participant's own words.
DropoutsA span where the link to the strap was lost is padded with zeros so the time axis holds, and annotated, for example Dropout ECG 4.0 s (padded).
Time axisThe file's own sample axis: onset = sample number ÷ 130. The strap's clock runs about 0.19 % fast against wall time, so over a night the file is slightly longer in samples than the clock says. The CSV beside the file records the measured rate. Use it to place a file second on the wall clock.
IdentificationThe header's first field reads code sex birthdate name. Where a Study ID is set under Your details, it takes the code position. The sample reads DEMO_01 X X X: study ID only, the rest unknown.
Lead notesA note at time zero says what wrote the file and that it is a single bipolar chest lead and not a medical device.
